Hướng Dẫn Đưa Lên Online Miễn Phí Vĩnh Viễn

Chỉ cần 1 file HTML duy nhất này, Huynh có thể đưa lên mạng chạy vĩnh viễn 24/7, mở trên điện thoại (iPhone/Android) hay bất kỳ máy tính nào bằng đường link riêng (vd: huynh-smc.pages.dev hoặc github.io).

Cách 1: Sử dụng GitHub Pages (Khuyên Dùng, 2 phút)
  1. Truy cập github.com và đăng ký tài khoản miễn phí.
  2. Bấm dấu + → Chọn New repository → Đặt tên (vd: smc-trading-hub) → Để Public → Bấm Create repository.
  3. Đổi tên file HTML này thành index.html rồi kéo thả tải lên (Upload files) → Bấm Commit changes.
  4. Vào tab Settings → Menu Pages bên trái → Chọn branch main rồi bấm Save.
  5. GitHub sẽ cấp cho Huynh link: https://<username>.github.io/smc-trading-hub/!
Cách 2: Kéo Thả 30 Giây Với Netlify Drop
  1. Đổi tên file thành index.html và cho vào 1 thư mục bất kỳ.
  2. Mở trang app.netlify.com/drop.
  3. Kéo thả thư mục đó vào. Trang web sẽ trực tiếp online ngay lập tức với link HTTPS có sẵn.
